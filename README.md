### 🧩 Featured Projects:

#### 🎨 **Profolify — Visual Portfolio Builder**
A no-code portfolio builder: pick one of eight templates, edit on a **live canvas**, then publish to a URL or **export a static site you own**.
Three-pane visual editor with drag-and-drop elements, per-node styling with separate mobile overrides, and undo/redo. One renderer serves the canvas, the published page and the export — so what you edit is what you ship.
`Next.js 15` `React 19` `TypeScript` `Tailwind CSS v4` `Firebase` `dnd-kit` `Zod` `TanStack Query`
🔗 [profolify.app](https://profolify.app)

#### 💥 **WreckTheWeb — Chrome Extension Game**
Freeze any web page and smash it apart with a khukuri, guns, rockets and fire — alone, or with up to **eight friends in real-time multiplayer**. Press `Esc` and the page is exactly as it was.
`TypeScript` `Chrome MV3` `WXT` `PixiJS (WebGL)` `matter.js` `Cloudflare Workers` `Durable Objects`
🔗 [Get it on the Chrome Web Store](https://chromewebstore.google.com/detail/bjnkckikfkolcibnfgfdpgceiliimjpp) · 📺 [Watch the demo](https://youtu.be/OPkndweMXF0)

#### 🛡️ **Lucid — On-device Computer Vision**
An **open-source** Chrome extension that blurs explicit, suggestive and graphic posts on Instagram and TikTok using a fine-tuned vision transformer running **entirely in the browser**. No servers, no tracking, no images leaving your machine.
`TypeScript` `Chrome MV3` `ONNX Runtime Web` `ViT-Tiny` `PyTorch` `Hugging Face`
🔗 [github.com/darshanbajgain/lucid](https://github.com/darshanbajgain/lucid)

#### 📺 **Retune — A TV That Never Stopped Broadcasting 2010**
Eleven channels airing right now, whether or not the tab is open. You can't pause, scrub or pick — you can change the channel, and that's all. What's on air is a pure function of the wall clock, so there's no backend and two viewers see the same frame.
`React 19` `Vite` `JavaScript` `CSS`
🔗 [retune-tv.vercel.app](https://retune-tv.vercel.app)
